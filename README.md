# Study Materials Repository

Welcome to my study materials repository for **Assembly Language Programming (x86 Architecture)**

## 📌 Introduction

This repository contains study materials, notes, and resources related to my Assembly Language Programming course focused on x86 architecture. It's a curated collection of files that helped me understand low-level programming concepts better. If you're not part of my class or batch, feel free to skip this repo.

## 📂 Contents

- **📘 Lecture Notes** – Concepts like registers, memory addressing, stack, flags, interrupts, etc.
- **🧪 Lab Assignments** – Exercises and tasks given in class for hands-on practice.
- **💻 Code Snippets** – Sample NASM/Intel-style assembly code demonstrating basic to advanced operations.
- **🛠 Mini Projects** – Small projects like string manipulation, simple calculator, etc.
- **📑 Reference Tables** – Instruction set references, register maps, and calling conventions.
- **🌐 Useful Resources** – Links to helpful tutorials, cheat sheets, and documentation.
